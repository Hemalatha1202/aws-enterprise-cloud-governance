# AWS Cost Optimization & Cloud Governance

## Project Overview

This project demonstrates AWS cost optimization,
resource governance, monitoring, security and
Infrastructure as Code using Terraform.

## Technologies

- AWS
- Terraform
- EC2
- S3
- RDS
- IAM
- AWS Budgets
- SNS
- CloudWatch
- AWS Config
- GitHub Actions

## Objectives

- Monitor AWS resource usage
- Configure cost alerts
- Apply resource tagging
- Optimize AWS resources
- Implement IAM governance
- Automate infrastructure using Terraform
- Implement CI/CD for infrastructure
